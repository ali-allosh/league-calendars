١

أنشئ المستودع

يفتح صفحة الإنشاء والاسم مكتوب. تأكد أنه Public ثم Create repository.

إنشاء المستودع
٢

ارفع الملفات

يفتح صفحة الرفع. اسحب كل محتويات المجلد الذي فككتَ الضغط عنه (الملفات + مجلدات assets و ics و tools و .github) ثم Commit changes.
إن لم يُقبل مجلد .github في الرفع لا تقلق — الخطوة ٥ تنشئه لك.

فتح صفحة الرفع
٣

فعّل GitHub Pages

في الصفحة: Build and deployment ← Source: Deploy from a branch، ثم Branch: main ← /(root) ← Save.

فتح إعدادات Pages
٤

صلاحية الكتابة (مرة واحدة)

Workflow permissions ← Read and write ← Save. هذه تسمح للتحديث التلقائي بكتابة البيانات الجديدة.

فتح الإعدادات
٥

ملف التحديث التلقائي

الملف .github/workflows/refresh.yml مضمّن في الملف المضغوط ويعمل فور الرفع. إن لم تجده في المستودع بعد الرفع، افتح الرابط الجاهز واضغط Commit changes مرتين. يبدأ العمل فوراً: يبني ٢٠٠+ تقويم للأندية ويحدّث الأوقات والملاعب والقنوات الناقلة من FotMob تلقائياً ٤ مرات يومياً.

فتح الملف الجاهز
